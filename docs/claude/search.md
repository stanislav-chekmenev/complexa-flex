# Test-time search — success gates, parity, evaluate

Deep invariants for best-of-N / adaptive search and confidence-head evaluation. Read this file
before touching `src/proteinfoundation/search/`, `src/proteinfoundation/confidence/inference_scorer.py`,
`src/proteinfoundation/generate.py` (search paths), or any `configs/search_binder_*` /
`configs/evaluate_*` config. Head architecture lives in [confidence.md](confidence.md).

- **Confidence-head provisional gate ≠ AF2 reporting gate.** The confidence head labels *provisional* successes during best-of-N search with a tightened gate (ipAE < 7 Å AND complex pLDDT > **0.92**; the head is overconfident vs AF2-multimer, so the higher pLDDT floor filters which candidates get AF2-refolded). This is a DIFFERENT gate from the **AF2 final / headline / target-count** gate, which **must** use the canonical published AlphaProteo rule (i_pAE·31 ≤ 7, pLDDT ≥ **0.90**, scRMSD_ca < 1.5) so success counts stay comparable to the binder-design literature (Bennett et al. / AlphaProteo, BindCraft). Never collapse the two: the head's 0.92 is a selection knob (`inference_scorer.SUCCESS_PLDDT_01`); the AF2 0.90 is a community-parity reporting constant (`DEFAULT_PROTEIN_BINDER_THRESHOLDS`, used verbatim, never mutated). Corollary: **any confidence-head-vs-AF2 parity number computed only over the head's selected provisional successes is a range-restriction artifact and is NOT valid evidence** of head quality — rank (Spearman) and linear (Pearson) correlation both attenuate to ~0 under the truncated predictor range, and a ×31 ipAE rescale (AF2 stores `i_pAE`/31, head is raw Å) does not change either, since both are scale-invariant. A valid parity needs AF2 scores on the full candidate pool (head-accepted AND head-rejected) stratified across the head's confidence range, led by a precision-at-gate confusion. See memory `confhead_parity_range_restriction`.
- **Confhead evaluate = scRMSD only.** Confhead evaluate must score ONLY head-successful samples (`provisional_success`) and compute ONLY AF2-multimer complex scRMSD (the head supplies all interface metrics). The config MUST override `metric:` to disable ESMFold monomer / esm / designability metrics or they starve the AF2 budget. scRMSD needs AF2-multimer, not ESMFold (complex, not monomer). See memory `confhead_evaluate_scrmsd_only`.
- **Interface ipAE is OOD on the concat frame.** The confidence head's INTERFACE ipAE is out-of-distribution on the binder-gen concat frame (head trained on co-diffused native dimers, not concat-target). Score in the native co-diffused `[binderA|targetB]` single frame the head trained on (Alt B: decode + assemble + re-encode), and log the cheap concat-reuse ipAE alongside for a Spearman-vs-AF2 parity check. ipAE < 7 in Ångström, no ×31. See memory `confhead_interface_extended_frame`.
