## 1. Root-cause analysis

`Proteina.training_step` (`src/proteinfoundation/proteina.py:212-271`) prepares the batch in this order before invoking the trunk:

1. `add_clean_samples(batch, cfg_exp.product_flowmatcher, autoencoder)` (`utils/sample_utils.py:42-59`). Adds `batch["x_1"]: Dict[str, Tensor]` keyed by modality. For `bb_ca` it copies `batch["coords_nm"][:, :, 1, :]`; for `local_latents` it runs `autoencoder.encode(batch)["z_latent"]`. **Required** before `corrupt_batch`.
2. `fm.corrupt_batch(batch)` (`flow_matching/product_space_flow_matcher.py:163-192`). Reads `batch["coords"]` + `batch["mask"]` (or `mask_dict`) via `process_batch`, then writes `batch["x_0"]`, `batch["x_1"]`, `batch["x_t"]`, `batch["t"]` (per-modality dicts), `batch["mask"]`. Internally samples `t` via `sample_t` from `cfg_exp.loss.t_distribution`. **Required** to populate `t` and `x_t` for the trunk.
3. `handle_batch_conditioning(batch, bs, training_cfg, call_nn, fm)`. Sets up CFG dropout, motif conditioning, fold-class labels, recycling count `n_recycle`. For pLDDT distillation we want the deterministic, fully-conditioned forward (no CFG dropout, no motif scaffold, no random recycling). **Not required**; sidecar should bypass.
4. `self.call_nn(batch, n_recycle=n_recycle)`. Runs trunk; iterative recycling. **Not required** for distillation at `t = trunk_eval_t = 0.99` — recycling is for sampling-time refinement and adds compute. Use a single forward (`n_recycle=0` equivalent, i.e. call `self.proteina.nn(batch)` directly).

`LocalLatentsTransformer.forward` (`nn/local_latents_transformer.py:218-343`) reads from the batch:
- `input["mask"]` (line 246).
- `input["t"]` via `cond_factory` (`seq_cond_feats.py:219,235,250`).
- `input["x_t"]` via `init_repr_factory` and `pair_repr_builder`.
- Optionally `input["seq_target"]`, `input["seq_target_mask"]` (target cross-attn path).

**Required keys at trunk entry**: `mask` (bool `[b, n]`), `x_t` (`Dict[str, Tensor]`), `t` (`Dict[str, Tensor[b]]`), plus any extra feature keys the configured `init_repr_factory` and `cond_factory` declare. The sidecar must therefore reproduce steps 1–2 (`add_clean_samples` + `corrupt_batch`) on the incoming batch before calling `self.proteina.nn(batch)`, and then deterministically pin `t = trunk_eval_t` everywhere.

## 2. Preferred fix design

**Pick Option A** (call `corrupt_batch`, then post-stamp `t` and recompute `x_t = fm.interpolate(x_0, x_1, t_pinned, mask)`).

- `proteina.py` and `local_latents_transformer.py` are not edited (spec §3.5 sidecar constraint, PR-1 sealed).
- Uses only public APIs already present on `ProductSpaceFlowMatcher`: `corrupt_batch`, `interpolate` (lines 105-133), and `data_modes` (the iterable used to build `t` and `x_t` dicts).
- Deterministic — the random `t` from `sample_t` is overwritten before any consumer reads it; `x_0` (noise) is the only stochastic input retained, which is correct: at `t=0.99` the interpolant is dominated by `x_1` (data) and `x_0` contributes ~1% — matches AF2 pLDDT regime.
- Option B (factor helper out of `proteina.py`) is rejected by spec.
- Option C (monkey-patch `sample_t`) is fragile (thread-safety, exception-cleanup, harder to test) and re-runs `interpolate` twice anyway; rejected.

**Cond computation (Path P2)**: keep `_compute_cond` separate, but call it on the *same* batch that the trunk sees (after `t` is pinned). The trunk re-runs `cond_factory(batch)` internally; the head re-runs it via the sidecar. Both see identical `t`, so AdaLN regimes match. PR-1 hook is not extended.

## 3. Concrete edits to `_forward` (pseudocode)

`src/proteinfoundation/confidence/lightning_module.py:196-225`. Replace `_forward` body:

```
def _forward(self, batch):
    with torch.no_grad():
        batch = add_clean_samples(
            batch,
            self.proteina.cfg_exp.product_flowmatcher,
            getattr(self.proteina, "autoencoder", None),
        )
        batch = self.proteina.fm.corrupt_batch(batch)
        b = batch["mask"].shape[0]
        device = batch["mask"].device
        t_pinned = {
            m: torch.full((b,), self.trunk_eval_t, device=device, dtype=batch["t"][m].dtype)
            for m in batch["t"]
        }
        batch["t"] = t_pinned
        batch["x_t"] = self.proteina.fm.interpolate(
            x_0=batch["x_0"], x_1=batch["x_1"], t=t_pinned, mask=batch["mask"],
        )

        self.proteina.nn.expose_intermediates = True
        nn_out = self.proteina.nn(batch)

    cond = self._compute_cond(batch)         # uses batch["t"] == trunk_eval_t
    inter = nn_out["trunk_intermediates"]
    s, z, mask_ext = inter["s"], inter["z"], inter["mask"]
    orig_mask = inter["orig_mask"]
    n_orig = int(inter["n_orig"])

    head_out = self.head(s, z, mask_ext, cond)
    logits = head_out["plddt_logits"][:, :n_orig, :]
    ...
```

Imports to add at module top: `from proteinfoundation.utils.sample_utils import add_clean_samples`.

Notes:
- The whole pre-head block (incl. `cond`) is under `torch.no_grad()` — addresses pytorch-jax minor.
- `_compute_cond` no longer constructs a separate `cond_batch`; the input batch already carries pinned `t`. Simplify: drop the dict-copy, keep the `expected_dim` guard. Wrap in `torch.no_grad()` for docstring honesty.
- `self.proteina.cfg_exp.product_flowmatcher` and `self.proteina.fm` are stable public attributes (`proteina.py:78,93`-ish — confirm during implementation).

### `metrics.py` (`src/proteinfoundation/confidence/metrics.py`)

Add `expected_calibration_error(logits, labels_bin, mask, num_bins_ece=10) -> Tensor`:
- `probs = softmax(logits, dim=-1)`; `conf, pred = probs.max(dim=-1)`.
- `correct = (pred == labels_bin).float() * mask`.
- Bucket `conf` into `num_bins_ece` equal-width buckets in `[0, 1]`.
- Per bucket `b`: `acc_b = correct[in_b].sum() / mask[in_b].sum()`, `conf_b = conf[in_b].mean()`, weight `n_b / mask.sum()`.
- Return `Tensor([scalar])`; guard against empty buckets (skip with weight 0).
